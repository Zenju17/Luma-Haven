# Migration plan

The prepared `core.0002` is unapplied: nullable hotel organization, organization and membership tables, unique memberships, and date/occupancy/percentage checks. It does not backfill, enforce membership or implement tenant isolation. It does not drop existing data. It validates all existing rows and may take locks. Inspection found no violating rows, but rerun immediately before deployment. Resolve any violations with the owner; never silently delete or fabricate records. The configured URL is not confirmed for Luma-Hotel; fix and verify database identity and role before any migration.

1. Establish a verified backup and restore test, staging clone and deployment window. Record migration state, constraints and row counts; run checks on the clone and run concurrency/API tests against isolated PostgreSQL.
2. Re-run preflight checks for date, occupancy and percentage violations, and test application compatibility under production-like load. Apply Django migrations only to the verified target. Monitor locks and failures; the PostgreSQL migration is atomic by default, but confirm applied state before retrying.
3. Map existing hotels and staff to organizations and property assignments with explicit owner review; backfill in bounded batches. Validate counts and cross-property relationships; no membership grants are automatic. Introduce scoped API/services, property-level permissions and cross-tenant tests before enabling another property.
4. Add nullable ownership to operational records, backfill, verify and index, then enforce constraints/non-null only after validation. Introduce audit and durable outbox, provider idempotency and tested RLS separately. Use staged constraint validation/concurrent indexes where table size warrants.

Prefer forward fixes. Reversing 0002 would remove newly created membership tables and organization associations: do not reverse once populated. Recovery uses tested backup/PITR in a separate instance and reconciliation of writes made after the recovery point; do not reset production.
